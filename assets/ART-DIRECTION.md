# Riftbound pixel-art assets

Generated with the built-in `image_gen` tool for this project, then copied into this directory. No external asset service or runtime image URL is used. Originals remain in the Codex generated-images directory. Ascension renders these original assets at full screen resolution with smooth downsampling. Sprite source regions are in `src/client/rendering/pixel-art.ts`; scalable UI emblems are authored in `src/client/ui/icons.ts`.

## Rendering notes

The generated atlases use hand-registered source rectangles rather than relying on exact uniform output spacing. UI portraits use the detailed actor atlas. Gameplay heroes use the six-column walk sheet at ten frames per second while moving. Environment props fade near the player to keep combat readable. Actors, terrain, effects, and particles are rendered into a half-resolution Canvas and scaled without smoothing. Boss variants reuse the Warden, revenant, and shaman artwork at larger scale with different attack patterns.
